MP7 — MCP Setup & Troubleshooting

Before you start
This is a quick setup and troubleshooting reference for Mini Project 7. The full assignment and rubric live on the Mini Project 7 — MCP Server page. You are building a FastMCP server that wraps the Practice Hub API so Claude Code can read, create, and modify your posts.

1. Your Practice Hub URL and token
API base: https://practice.fhsucyber.com (the same Hub as Mini Project 1)
API reference: https://practice.fhsucyber.com/docs-guide
You already have a token from Week 1. Lost it? Re-issue one by POSTing your email and password to /api/v1/auth/token.
Set both as environment variables — never hard-code or commit your token:
macOS/Linux:export PRACTICE_API_URL="https://practice.fhsucyber.com"export PRACTICE_API_TOKEN="your-token-here"Windows PowerShell:$env:PRACTICE_API_URL = "https://practice.fhsucyber.com"$env:PRACTICE_API_TOKEN = "your-token-here"
2. The five tools you implement
Each tool calls one endpoint and needs a clear docstring — the model reads docstrings to decide when to call a tool. Send Authorization: Bearer <your token> on every call.

list_posts → GET /api/v1/posts (support ?mine=true)
get_post → GET /api/v1/posts/{id}
create_post → POST /api/v1/posts with title, body, tags
update_post → PATCH /api/v1/posts/{id}
delete_post → DELETE /api/v1/posts/{id}
3. Register the server with Claude Code
The default MCP transport is stdio — your server runs as a local subprocess:

claude mcp add practice-hub -- python server.pyclaude mcp list        # confirm it registered
Then ask Claude Code to list your posts; it should call your tool.

4. The acceptance test (what you must demonstrate)
Through your server, Claude Code should read your posts, create a new post, and modify an existing one. Capture a transcript or screenshots in your repo.

5. Common errors — handle them, do not crash
401 "Missing or invalid Authorization header" → your token is not set or not sent as Bearer. Check PRACTICE_API_TOKEN and your request header.
403 → you tried to edit or delete a post that is not yours. Return a clear message instead of crashing.
404 → that post id does not exist. Return a clear message.
Claude Code cannot see your server → confirm stdio transport, and make sure server.py does not print() to stdout. stdio uses stdout for the protocol; log to stderr instead.
6. Keep your token out of git
Read it from os.environ and add any secrets file to .gitignore. A token committed to a public repo is a real credential leak.
